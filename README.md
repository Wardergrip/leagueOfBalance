# League Of Balance

This is the initial version, prototype if you will, for [League Junction](https://github.com/League-of-DAE-Legends/LeagueJunction).

The initial idea was to have a Discord bot which would make it easily accessible for anyone to use this tool, however, as we were students and did not want to have monthly costs we opted for a GUI tool that had to be downloaded and run. (See League Junction)

In case you're wondering why I chose for C++ for a Discord bot: C++ was what I was most familiar with at the time and it seemed a fun challenge to do a 'web project' in C++.
